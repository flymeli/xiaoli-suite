# 校哩（xiaoli-suite）

校哩是面向经核验在校大学生的校园生活与兴趣社区。学生完成学籍核验后，可以在本校空间里分享图文、纯文字和基础短视频，也可以在作者允许的范围内发现其他学校的内容。首期先验证同校回应和社区治理，集市、广告分成和群聊放在后面。

本仓库目前存放产品理解与原型盘点文档，还不是应用源代码。产品规则以《校哩App 产品规划与需求规格 V1.0》（2026-11-06）为准。继续完善学生端原型时，以恒在 OpenDesign 中的这份稿为底，墙墙旧 HTML 只作参考。
