# 原型完善第一批：认证与学校状态

- 版本：说明稿 V0.1
- 日期：2026年11月17日（Asia/Shanghai）
- 底稿：用户 OpenDesign 项目 `6de335a6-f9e2-42a5-b799-5409948a2f2e` 的 `index.html`、`DESIGN.md`、`assets`。目录在 `prototypes/mobile/`。这不是墙墙 HTML，也不是另一套竞品视觉。
- 依据：`01` 的页面盘点和第一批顺序，`02` V0.4 的产品方向与 TECH，`04` V0.3 的认证证据。历史 source 只用来对照，不把旧稿里的 18 岁门槛、全日制默认、180 天复核或三种认证任选写回来。
- 这一批没有做完学生端。浏览、发布和私信的深度状态还在后面，同一分支可以继续补。

## 1. 这一批实际改了什么

保留原来的五入口、频道、内容卡、发布进度、评论、受控私信和视频控件。主题仍是底稿里的灰蓝 `#4B6CB7`、纸感底和描边按钮，没有改回 token 蓝，也没有把 `DESIGN.md` 里的健康管理业务搬进来。视频仍是详情页里的自有进度条，不是全屏上下滑。

登录和认证按 01 的 P0 边界收过：

- 欢迎页补了一句产品说明，并有帮助入口。
- 登录只留手机验证码。主按钮是「登录并进入认证」。协议可以点开再返回，表单还在。
- 密码注册、微信 / QQ / 支付宝登录从登录页拿掉。直接打开旧路由时，会说明它们不在首期，也不能代替学生认证。
- 短信标成「演示 / 待验证」。任意 6 位数字都能过，因为没有短信接口。

认证入口先到路径选择，不再跳过说明直接提交。可选：

| 路径 | 页面上的标记 | 原型里会得到什么 |
|---|---|---|
| 微信学生身份快速验证 | 官方候选 · 演示 / 待验证 | 模拟通过时只记学生身份，不写学校。不请求微信。 |
| 支付宝学生 / 校园身份 | 官方候选 · 演示 / 待验证 | 公开字段仍按 04 记为未知。模拟结果不是已接入。 |
| 掌上大学 | 官方候选 · 演示 / 待验证 | 没有公开接口证据，不把它当成已选定供应商。 |
| 扫码认证小程序 | 备用方案 · 演示 / 待验证 | 见下一节。占位图形写着「演示码 / 占位」，不是微信小程序码。 |
| 人工兜底 | 演示 / 待验证 | 不上传文件，不填身份证、人脸、学信网密码。声明学校不会自动变成归属。 |

不设 18 岁输入，也不用年龄失败。已毕业、结业、肄业的模拟材料不会通过。未成年人保护只在文案里标成未决，没有因此把私信改成谁都能发。

## 2. 扫码备用方案（只在浏览器里模拟）

已登录后才能生成会话。会话大约 90 秒，也可以立刻「模拟过期」。页面上的码是占位，不能扫。

1. 对方扫码只把后台状态改成「已扫码待确认」，学生标记不动。
2. 微信侧确认之后，还要发起方在 App 里再确认一次。
3. 只有点「从演示后台刷新」，界面才抄写后台结果。没有微信回调。
4. 双方都确认后，只更新学生身份。学校仍是未确认。
5. 取消、他人拒绝、过期、重放已消费凭证，都不会把原账号写成已认证学校。

这些按钮旁边的状态是原型内存，刷新页面就没了。

## 3. 学生状态和学校状态

两边分开存。学校未确认时，没有本校信息流、本校发布和本校成员权。只确认了学生的人，能不能看全站已认证内容，04 说还要产品决定，所以这一批不默认放开。

| 演示状态 | 校园 | 广场 | 发布 | 新私信 |
|---|---|---|---|---|
| 未开始 / 审核中 / 需补充 / 未通过可重试 | 停在说明，不自动通过 | 不开放 | 不可以 | 不开放 |
| 已毕业、结业、肄业 | 不默认通过 | 不开放 | 不可以 | 不开放 |
| 学生已确认，学校未确认 | 无本校权限 | 不默认开放 | 不可以 | 不开放 |
| 学生和学校都确认，学校筹备 | 无本校信息流 | 可看全站已认证内容 | 不可以 | 不开放 |
| 学校未开通 | 同上 | 可看全站已认证内容 | 不可以 | 不开放 |
| 学校暂停 | 同上 | 可看全站已认证内容 | 不可以 | 不开放 |
| 学校开放，资格示意有效 | 原来的本校信息流 | 原来的广场 | 原来的发布 | 原来的受控私信 |
| 续验处理中，旧资格仍有效 | 本校信息流还在 | 还在 | 还在 | 还在 |
| 资格失效 | 本校权限收回 | 不开放 | 不可以 | 不开放 |

学校目录有四所虚构学校：南川大学（开放）、北屿理工大学（筹备）、澄江学院（未开通）、望湖大学（暂停）。文案写明试点意向是四川大约两校，校名未锁定，配置可以再增删。广场里的内容学校仍是原来的南川和北屿，那是内容演示，不是开通名单。

资格文案写「复核暂定一年，未冻结」，不再把「下次复核 2027 年 6 月」当成政策。发布范围的「全站学生」改成「全站已认证学生」，并保留「不是互联网公开」。

认证页底部有「原型演示：直接查看各状态」。那是给走查用的开关，不是后台。

## 5. 明确不在这一批

- 消息页恢复「互动 / 系统 / 私信」分段、评论配图、校园单双列取舍。
- 群聊、钱包、广告、小红书式视频。
- 运营后台。
- 真实短信、微信、支付宝、学信网、掌上大学调用，以及任何平台注册或付费。
- 采集真实姓名、证件号、人脸或学信网密码。

## 6. 怎么自己点一遍

在 `prototypes/mobile` 打开 `index.html`。用演示手机号和任意 6 位验证码登录。然后走「选择认证路径」。要直接看某个状态，可以在地址后加查询参数，例如 `?preset=student_only&route=campus` 或 `?preset=open_member&route=videoDetail`。可选 preset：`none`、`reviewing`、`supplement`、`rejected`、`student_only`、`preparing`、`not_open`、`paused`、`open_member`、`expired`、`renewing`、`graduate_blocked`。`frame=360`、`390`、`430` 只改预览宽度。

## 7. 测试
