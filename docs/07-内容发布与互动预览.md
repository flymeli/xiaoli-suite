# 内容、发布和互动预览

- 日期：2026年11月17日
- 位置：`prototypes/mobile/`，仍是浏览器里的原型，不是业务后端。
- 素材：沿用底稿 `assets/stock` 和 `assets/video`。来源写在各自的 `credits.json`。没有新生成图片，也没有外链。

## 学生能做什么

- 校园和广场里有纯文字笔记、多图和图文、以及一条可播放的本地短视频。
- 详情可以看标题、段落、引用和列表。多图能预览。视频仍是原来的播放、暂停、进度和静音，不是上下滑。
- 点赞、取消点赞、收藏、取消收藏会改本地数量。评论和回复写在当前作品上。我的作品、我的收藏和信息流用的是同一份状态。
- 中间的加号可以写笔记、从相册选图、尝试拍照，或选择视频。拍照只有在浏览器允许时才会打开；桌面环境或权限失败时会说明，并可以改用本地文件或示例图片。示例视频是预览用的校园片段，不会被说成实拍成功。
- 正文里以 `>` 开头的一行是引用，以 `-` 开头的是列表。用户输入会转义后再显示。
- 发布范围默认仅本校，也可以选全站已认证学生。空正文不能发。发布成功后能在校园列表和我的作品里打开，并继续点赞评论。
- 这些内容保存在本机浏览器里。预览说明里可以重置。不会保存手机号或证件，也不会上传。

## 只是预览、不能当成已上线

- 认证结果、短信、微信、支付宝、学信网都没有真实调用。成功路径是原型里走完的闭环。
- 视频拍摄没有可靠的录像实现，预览里用示例片段代替。
- 没有审核后台、群聊、钱包或广告。
